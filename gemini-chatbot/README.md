# Follow these steps to get your own API key to Gemini 1.5.

# You must have your own API key for this to work.

1. Go to: https://makersuite.google.com/

2. Sign in with your Google account.

3. Click "Get API Key" in the left-hand menu (or under the gear/settings icon).

4. Copy your API key and paste it in the quotation marks.
